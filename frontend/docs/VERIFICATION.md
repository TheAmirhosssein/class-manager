# گزارش بررسی خروجی

بررسی در Chrome با اجرای خودکار Playwright انجام شد.

- بارگذاری صفحه اصلی و وب فونت محلی.
- فیلتر پایه، جست‌وجوی بدون نتیجه و پنجره جزئیات کلاس.
- ثبت حضور و غیاب و بازیابی وضعیت پس از reload.
- ثبت یادداشت انضباطی و نمایش امن متن حاوی تگ HTML.
- افزودن/حذف جلسه و رد کردن زمان دارای تداخل.
- ویرایش و ذخیره نام مدرسه.
- منوی موبایل و بررسی نبود اسکرول افقی در عرض‌های ۳۲۰، ۳۹۰، ۷۶۸، ۱۰۲۴ و ۱۴۴۰ پیکسل.
- باز شدن مستقیم index.html با file:// و بدون سرور.
- در حالت demo:false و با API شبیه‌سازی‌شده: پیام نشست نامعتبر، ورود، بازیابی نشست، ذخیره حضور و غیاب، ارسال هدر CSRF و خروج.
- بررسی syntax فایل‌های JavaScript با node --check؛ بدون خطای JavaScript در سناریوهای مرورگر.
- بازبینی تصویری صفحه دسکتاپ و موبایل.

این بررسی شامل اتصال به بک‌اند واقعی، بارگذاری روی دامنه، مرورگر Safari یا آزمون امنیتی سرور نیست. فایل‌های تست و ابزارهای توسعه بخشی از محصول موردنیاز برای اجرا نیستند. برنامه نهایی بدون پکیج خارجی اجرا می‌شود.
