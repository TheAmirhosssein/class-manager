# کلاسینو — پنل مدیریت کلاس

رابط فارسی و راست‌چین برای مدیریت کلاس، حضور و غیاب، انضباط و برنامه هفتگی. رنگ سبز و سفید و فونت محلی Yekan Bakh. نام مدرسه، دانش‌آموزان و کلاس‌ها در حالت نمونه هستند.

## اجرای سریع

فایل `index.html` را در یک مرورگر به‌روز باز کنید. اینترنت، نصب پکیج و build نیاز نیست. از ریشه مخزن: `make serve` → `http://127.0.0.1:8080`. فقط پیش‌نمایش استاتیک:

```sh
node serve.cjs
```

→ `http://localhost:4173`

پروژه به صورت فایل‌های معمول HTML/CSS/JavaScript است و به React، Node یا سرویس خاصی در محیط نهایی وابستگی ندارد. Node فقط برای سرور پیش‌نمایش اختیاری است.

## فایل‌ها

```text
index.html                   پوسته پنل و پنجره‌ها
assets/styles.css            طراحی، فونت، RTL و نمایش موبایل
assets/app.js                تعاملات و نمایش داده‌ها
assets/api.js                نقطه واحد ارتباط با API و داده‌های نمونه
assets/config.js             تنظیمات عمومی اتصال
assets/favicon.svg           آیکون سایت
assets/fonts/                چهار وزن وب فونت و فایل مجوز همراه
docs/API.md                  قرارداد پیشنهادی API و نمونه داده‌ها
docs/HANDOFF.md              راهنمای تحویل و تغییر محتوای نمونه
serve.cjs                    سرور اختیاری پیش‌نمایش محلی
```

## بخش‌های آماده

- پنل مدرس شامل نمای کلی، فهرست کلاس‌ها، حضور و غیاب، انضباط، برنامه هفتگی و نام مدرسه.
- ثبت حضور با تاریخ، بارگذاری وضعیت ثبت‌شده، چهار وضعیت حضور، دکمه همه حاضر و اعتبارسنجی فهرست کامل.
- یادداشت تشویق / پیگیری برای هر دانش‌آموز.
- افزودن و حذف جلسه هفتگی و تشخیص تداخل زمانی کلاس‌های این مدرس.
- حالت نمونه با ذخیره محلی؛ مسیر ورود API در حالت اتصال واقعی.

## اتصال به بک‌اند

در `assets/config.js` مقدار `demo` را به `false` تغییر دهید و `apiBase` را تعیین کنید. endpointها باید قرارداد `docs/API.md` را پیاده کنند. ترجیح این قالب، اجرای فرانت و API روی یک origin و استفاده از کوکی نشست HttpOnly است. هیچ رمز یا توکن محرمانه‌ای در کد قرار ندهید.

ورود نمونه احراز هویت نیست. داده نمونه در localStorage با کلید `classino.demo.v1` ذخیره می‌شود (نسخه قبلی `riazino.demo.v1` هم خوانده می‌شود). حذف این کلید، داده نمونه را به حالت اولیه برمی‌گرداند. در حالت API، داده‌های پنل از سرور دریافت می‌شوند و localStorage منبع داده نیست.

## فونت

چهار وزن Regular / SemiBold / Bold / ExtraBold از نسخه Webfonts فونت شخصی ارائه‌شده کپی شده‌اند. فایل `assets/fonts/FontLicense.txt` اصلی حفظ شده است؛ کد مجوز پروژه پیش از انتشار در همان فایل تکمیل شود.

## محدوده تحویل

این بسته فرانت‌اند قابل اتصال است. سرور احراز هویت، پایگاه داده، ارسال ایمیل، پرداخت، ویدئوی آموزشی و ثبت‌نام تجاری دوره‌ها در آن پیاده نشده‌اند. نمونه‌ها ادعای خدمات واقعی مدرس نیستند. نقش و دسترسی باید توسط بک‌اند کنترل شود.
